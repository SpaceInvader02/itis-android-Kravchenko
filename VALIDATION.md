Автотесты проверяют переход по кнопке и отображение произвольного значения, переданного через Intent, после пересоздания `SecondActivity`. Второй тест использует другие данные, поэтому отдельно подтверждает, что второй экран читает Intent, а не подставляет имя из ресурсов.

Предупреждения lint: 5 уведомлений о новых версиях зависимостей, `DataExtractionRules`, `TypographyDashes` для номера группы и отсутствие собственной иконки приложения. Они не препятствуют сборке и выполнению задания. Номер группы оставлен в точности как указал пользователь.

## Среда

Использованы JDK 17, Gradle 8.11.1, Android SDK Platform 35 и Build Tools 35.0.0. Контрольные суммы дистрибутивов проверены по данным официальных источников. Из-за сетевых тайм-аутов зависимости Gradle получены через зеркало Huawei, подключённое локальным init-скриптом; репозитории в исходниках проекта не изменены.

SDK и JDK находятся в рабочей папке рядом с `outputs`. Файл `local.properties` указывает на установленный SDK и исключён из Git. Инструменты и кэш не включены в архив исходников.

## Артефакты и сдача

Рядом с папкой проекта сохранены `Homework1-debug.apk`, скриншоты обоих экранов, скринкаст из запущенного приложения `Homework1-demo.mp4`, XML-отчёт тестов и текстовый отчёт lint.

Работа находится в ветке `hw1`, базовая ветка — `main`. Удалённого репозитория нет, поэтому push и PR не выполнены. При создании репозитория отправьте обе ветки и откройте PR `hw1` → `main`; оставьте его открытым для проверки преподавателем.
