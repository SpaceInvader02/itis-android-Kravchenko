# Homework 1: two Compose Activities with Intent data transfer

Добавлено Android-приложение на Kotlin и Jetpack Compose. Первый экран показывает имя и группу из `strings.xml`. По нажатию кнопки `MainActivity` передаёт строку `Фамилия Имя/группа` через Intent в `SecondActivity`, которая отображает полученное значение. Обе Activity зарегистрированы в манифесте.

В ресурсах указаны данные студента: Кравченко Евгений, группа 11-502; второй экран показывает `Кравченко Евгений/11-502`. Добавлены инструментальные проверки перехода и отображения произвольного значения из Intent после пересоздания Activity.

Проверка: см. `VALIDATION.md` для фактического результата локальной сборки. Скринкаст следует записать из работающего приложения и приложить к сдаче. PR оставить открытым для проверки преподавателем.
