# Домашнее задание №1 — Activity, Intent, Jetpack Compose

Первый экран показывает имя и группу через `Text`, значения берутся из `strings.xml` с помощью `stringResource`. Кнопка открывает `SecondActivity` и передаёт строку `Фамилия Имя/группа` через `Intent.putExtra`. Второй экран отображает именно полученную строку через `getStringExtra`. Обе Activity зарегистрированы в манифесте.

Приложение собрано и проверено на Android 7.0 (API 24): 2 автотеста прошли, lint — 0 ошибок и 8 предупреждений. Подробности находятся в `VALIDATION.md`. Готовый APK и скринкаст из работающего приложения сохранены рядом с папкой проекта.

## Перед сдачей

1. В `app/src/main/res/values/strings.xml` указаны данные пользователя: `Кравченко Евгений`, группа `11-502`. На втором экране ожидается строка `Кравченко Евгений/11-502`.
2. Откройте эту папку как проект в Android Studio. Используйте JDK 17 и установите Android SDK Platform 35 / Build Tools 35.0.0 через SDK Manager. Если SDK установлен в нестандартном месте, укажите `sdk.dir` в локальном `local.properties` (файл не коммитится).
3. Выполните `gradlew.bat assembleDebug lintDebug` в Windows или `./gradlew assembleDebug lintDebug` в Linux/macOS. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
4. Запустите приложение на телефоне или эмуляторе с Android 7.0 (API 24) или новее. Для инструментальных тестов выполните `gradlew.bat connectedDebugAndroidTest` при подключённом устройстве.
5. Приложите скринкаст **из запущенного приложения**: запуск → первый экран с именем и группой → нажатие кнопки → второй экран с объединённой строкой. Такая запись уже сохранена в `Homework1-demo.mp4` рядом с папкой проекта. При необходимости запишите её заново на своём устройстве. Картинки исходного кода не заменяют скринкаст.

```powershell

git push -u origin main

```
